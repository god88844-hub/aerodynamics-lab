# M17 — Peer-reviewed G30×10.5 static propeller measurements, installation-aware audit

The primary AeroForge goal remains quantitative agreement of predictions with *independent physical measurements* within actual, predeclared operating and measurement uncertainty envelopes. This milestone adds a more hardware-relevant independent **published experimental thrust campaign** but deliberately DOES NOT treat an assembly mismatch as flight validation.

## Published experiment (citation / license)

Mădălin Dombrovschi, Gabriel-Petre Badea, Tiberius-Florian Frigioescu, Maria Căldărar, and Daniel-Eugeniu Crunțeanu, **“Ground Effect Influence on UAV Propeller Thrust: Experimental and CFD Validation”**, *Technologies*, 13(12), article 542, November 21, 2025. DOI [10.3390/technologies13120542](https://doi.org/10.3390/technologies13120542), [full paper](https://www.mdpi.com/2227-7080/13/12/542).

Open-access [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) publication ([MDPI rights policy](https://www.mdpi.com/about/openaccess)). The numerical Table 5 was transcribed into `data/benchmarks/public/g30_2025/bench_table_5.json`. The numerical values are **the authors' published measurements**, not generated by AeroForge or a new bench experiment. Original high-frequency sensor logs are available from the corresponding author on request, not provided here. Exact nine-row transcription is pinned by canonical SHA-256 so an apparent typo cannot be silently “corrected” or hidden.

### Scientific comparability: same propeller, different apparatus

| Dimension | Published physical test | AeroForge 60kg capstone |
| --- | --- | --- |
| Propeller | T-MOTOR G30×10.5 CF, 30in | **Same published propeller geometry** |
| Motor | T-MOTOR **MN1010 KV135** | T-Motor **P80 III KV100** |
| ESC | Flame 100A 14S | Different reference ESC |
| Mount | 350×250mm plate ~50mm behind propeller, flow interference | Actual matching plate distance and flow boundaries unknown |
| Experiment | Nine steady static operating points at 368–2305 rpm | P80 III manufacturer's own static bench table spans 1719rpm upward |
| Sensor | Flintec PA1 load cells; HX711; calibration reportedly under 3% | Different manufacturer bench method; independent hardware match not established |
| Valid comparison | Only RPM-overlapping **descriptive thrust differences** (1900, 2171, 2305 rpm) | **NOT** blind model validation / electric-power comparison |

The study reports the mounting plate can change thrust substantially (roughly 25–30% relative to isolated setups). A physically accurate AeroForge model needs installation geometry and independent field tests, not a universal multiplier obtained from another test stand. Therefore **no M17 code changes the propulsion model, battery, geometry, capstone reports or airworthiness verdict**.

The paper's Table 5 includes a conspicuous source-data problem:

- Case #2: reported voltage 46.2 V and current 0.7 A (product **32.34 W**) but printed electrical power **3234 W**.
- M17 retains the **original reported 3234 W**, computes `V*I` independently, flags the inconsistency and refuses that row as reliable independent electrical-power evidence. This is a source provenance warning, not a new measurement.
- The rest of the published values are checked for consistency with a 2%/0.25W **data QA threshold**; this threshold is for spotting transcription inconsistencies, **not** a scientific validation tolerance.

## Implemented

- Full nine-row published source table, attribution, explicit different-motor and mount metadata, source-error annotation.
- `packages/physics/validation/g30_installation.py`: fail-closed source checks; published-table SHA-256; electrical consistency audit; **P80 III measured RPM envelope only**; out-of-envelope exclusion; descriptive measured-vs-reference thrust differences; no correction-factor fitting or false physical validation.
- `GET /api/components/public-g30-benchmark`, plus real-data panel under the AeroForge evidence workbench.
- Python model/API and frontend regression tests covering the 3234-W source typo, strict lack of extrapolation, hardware mismatch, source mutation and no positive equivalence verdict.
- `data/benchmarks/public_sources.json` updated with one more close-to-hardware physical study.

## Remaining necessary before physical equivalence is established

1. Independently measured thrust/RPM/current/torque for the **actual P80 III KV100 + G30 CF + ESC** with matching physical mount (including ground-proximity, vortex interference and measured wind).
2. Measured actual flight batteries under mission 7–8C load, timed capacity/temperature/aging envelopes, independent physical instruments and raw synchronized timestamps.
3. Blind flight telemetry from multiple actual assembled reference multirotors, full controller/actuator identification, validated wind/environment, modeled uncertainty and preregistered error bands.
4. Qualified aerospace review of all physical loads, structural failure modes, electrical protection, numerical/model-form limitations and safety controls.

No experiment in this peer-reviewed paper is a direct safety or manufacturing-success guarantee for the user's complete aircraft. Such tests remain independently required and tracked in [issue #16](https://github.com/god88844-hub/aeroforge/issues/16).
