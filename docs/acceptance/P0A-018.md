# P0A-018: 3D multirotor geometry editor, undo/redo, and Fusion-style CAD materials

Status **DEVELOPMENT / SOFTWARE VERIFICATION**. Physical acceptance remains **UNVALIDATED**. Base `03c4863` (`Merge pull request #142 from god88844-hub/feature/p0a-017-desktop-workflow`).

## Entry points and scope

- Standalone 3D CAD editor (`apps/desktop/main.gd`):
  - Supported parametric solid & blade editing (`_open_body_editor`, `_rebuild_body`, `_open_blade_editor`, `_rebuild_blade`) backed by Open CASCADE / CadQuery workers (`build-body`, `build-blade`), with explicit station radius constraints (`tip_radius_m > root_radius_m`) and explicit scope banner (`Supported parametric body & blade CAD (Open CASCADE) · not full freeform sketcher`).
  - Assembly node transform editing (`_open_transform_editor`, `_apply_node_transform`, `_euler_deg_to_wxyz`) updating active Hamilton `orientation_wxyz` unit quaternions and `position_m` through `lab_project.py validate`.
  - Undo/redo stack (`_push_undo_state`, `_undo_edit`, `_redo_edit`, `_adopt_project_with_undo`) restoring exact `project`, `project_asset_root`, and `project_document_json` alongside visible `ImporterMesh` LODs without altering exact STEP geometry.
  - Display-only Fusion-style CAD PBR presets (`_make_cad_material`, `_on_cad_material_selected`: `anodized_blue`, `alu_6061_t6`, `cfrp_quasi_iso`, `pa12_nylon`), edge/selection rim shading (`rim_enabled = true`), and Studio/Outdoor HDRI-style lighting toggle (`_toggle_lighting_mode`).
- Godot desktop verification (`apps/desktop/smoke_test.gd`): exercises `_open_blade_editor`, `_rebuild_blade`, `_open_transform_editor`, `_apply_node_transform`, `_undo_edit`, `_redo_edit`, `_on_cad_material_selected`, and `_toggle_lighting_mode` in `desktop-foundation` CI.
