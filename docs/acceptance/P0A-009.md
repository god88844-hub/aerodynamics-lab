# P0A-009 — Correct and verify the supported signed aerodynamic regime

**Status**: DONE · **Actor**: builder · **Date**: 2026-11-22 · **Commit under audit at start**: `b556697`

## 1. Canonical signed-regime implementation (`packages/physics/aerodynamics/axial_prop.py`)

New module (alongside the existing `drag.py`), implementing the frozen M24
coefficient protocol as the canonical flight-engine model of record:

- **Exact SI equations** (n in rev/s, D in m, ρ in kg/m³ per
  `docs/VALIDATION_TOLERANCES.md`'s M24 definitions):
  `J = V_a/(nD)`, `T = ρn²D⁴·CT(J,RPM)` (signed — CT < 0 is windmilling),
  `Q = ρn²D⁵·CP(J,RPM)/(2π)`, `P = 2πnQ = ρn³D⁵·CP`. Verified exactly
  (identity residuals at float round-off; `P == 2πnQ` holds bit-exactly).
- **Body-frame projection**: `body_frame_force`/`body_frame_torque` project
  the signed thrust/torque on the declared rotor axis (normalized, fail-closed
  on zero/nonfinite axes). Flipping the axis flips the force; magnitude is
  orientation-invariant.
- **Sign preservation end-to-end**: positive CT → positive thrust/torque/
  power; negative CT (windmilling, reachable inside the envelope) → negative
  thrust while the shaft still absorbs power (CP > 0); the analytic load at
  the zero-crossing J is ~zero thrust (continuity across the crossing — no
  sign clamping anywhere).
- **Fail-closed envelope contract**: `AxialEnvelopeError` (typed) refuses
  `n ≤ 0`, reverse/vortex-ring axial inflow (`V_a < 0` — declared unmodeled),
  RPM or J outside the declared calibration envelope, and nonfinite/invalid
  inputs. `classify()` provides explicit non-fatal `out_of_envelope: <reason>`
  labeling when a caller declares it wants names instead of refusals. The
  envelope and diameter are **caller-declared inputs bound to frozen
  calibration evidence** — nothing is hardcoded per propeller; inverted or
  out-of-plane-support envelope declarations are refused at construction.
- **Frozen-protocol bridge**: the canonical interpolation reproduces the
  frozen M24 protocol's `interpolate()`/blend **bit-exactly** on the pinned
  calibration knots (asserted on a 41-point J grid and the same mix form), so
  benchmark code and flight-engine code cannot drift apart.

## 3. Principled resolution-aware classification (guardrail honored)

**No predicted-side count threshold exists.** The rule, as locked in the
delta artifact:

- **Measurement sign indeterminacy** depends only on the instrument/table
  resolution: `|CT_meas| ≤ δ_res = 0.0001` (the 4-decimal source format).
- **Prediction quality** is judged separately against the **predeclared**
  M24 tolerances in `docs/VALIDATION_TOLERANCES.md` (policy v1.0.0,
  PROSPECTIVE_PENDING_OWNER_AND_QUALIFIED_REVIEW): CT MAE ≤ 0.001, CP MAE
  ≤ 0.0005 (recorded with provenance in the artifact).
- Labeled as a **DEVELOPMENT protocol revision locked prospectively** for
  future confirmatory holdouts; **no M24 physical acceptance is claimed** from
  DEVELOPMENT data.

## 6. Honest scope

The canonical signed regime is an interpolation model of measured wind-tunnel
coefficients inside the measured envelope — no blade-element physics, no
Reynolds/Mach correction, no off-axis or installed-interference behavior.
The resolution-aware sign rule is a DEVELOPMENT protocol revision locked
prospectively; it does not validate the propeller model physically, and M24
acceptance remains open pending predeclared-tolerance confirmation on
confirmatory holdouts with calibrated uncertainty and qualified review.
