# P0A-022: Missions, controls, clocks and experiment seeds

Status **DEVELOPMENT / SOFTWARE VERIFICATION**. Physical acceptance remains **UNVALIDATED**. Base `688ab55` (`Merge pull request #143 from god88844-hub/feature/p0a-018-cad-editor-pbr`).

## Entry points and scope

- Deterministic mission authoring & replay (`packages/physics/scenarios/mission_authoring.py`):
  - `MissionPhase` (`takeoff`, `climb`, `hover`, `descent`, `landing`, `manual`), `MissionDisturbance`, `MissionPlan`, `author_mission`, and `run_authored_mission`.
  - Executes on an integer-stepped fixed simulation clock (`controller_dt_s`) seeded with `numpy.random.Generator(PCG64(seed))` and serialized sensor noise/latency parameters, completely decoupled from `render_fps_hint` (render cadence). Produces deterministic SHA-256 mission/result receipts (`mission_sha256`).
- Worker & desktop UI integration:
  - `scripts/lab_project.py author-mission` and `run-mission`.
  - `apps/desktop/main.gd`: `_open_mission_dialog`, `_run_authored_mission`, and `Mission / Seeds` UI controls.
