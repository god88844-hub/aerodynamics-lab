  - `stage_standalone_package(...)` bundles desktop definitions (`apps/desktop/`), local shared services (`apps/api/app/services`), physics/CAD/optimization/schema packages, local worker scripts (`scripts/lab_project.py`, `scripts/lab_worker.py`, `scripts/lab_cad_analysis.py`), locked requirement manifests (`apps/api/requirements.lock`, `apps/desktop/requirements-cad.lock`), reference components/designs/protocols, `LICENSE`, `NOTICE_STANDALONE.txt`, and SHA-256 `package_manifest.json` with `http_server_required=False`.

  - `recover_user_project_after_corruption(...)` restores last valid snapshots after corrupt project writes.
