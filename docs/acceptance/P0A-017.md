- Standalone Godot 4.7 UI (`apps/desktop/main.gd`):
  - Toolbar & dialogs for `New project`, `Import design`, `Load reference`, `Open project`, `Save project`, `Save version`, `Versions / Recover` (`_open_new_project_dialog`, `_create_new_project`, `_import_design`, `_open_project`, `_save_project`, `_save_version`, `_open_versions_dialog`, `_reopen_selected_version`, `_recover_last_valid`) with zero HTTP server dependency.
  - Dual visual profile (`_apply_visual_profile`, `_cycle_visual_profile`): configures `Forward+` PBR (`ProceduralSkyMaterial`, `TONE_MAPPER_ACES`, glow, SSAO, directional shadows, PBR material presets) when a Vulkan `RenderingDevice` is active, and falls back to `gl_compatibility` on baseline Tier 1 laptops and headless Linux CI without altering engineering geometry or physics.
- Error handling & recovery: malformed JSON (`corrupt_document`), incompatible `document_version` (`incompatible_version`), missing assets (`missing_asset`), and SHA-256 mismatches (`corrupt_asset`) fail closed with typed error categories without overwriting saved projects, while `.aerolab-recovery/last-valid.json` preserves and restores the last valid snapshot and assets.
