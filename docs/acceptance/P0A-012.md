# P0A-012: Propagate per-rotor electrical and supported actuator failures

Base: `23a02fb454f371de82010a96bc34636b1652db90` (approved P0A-011).
This is software verification with synthetic loads and faults on the sourced
bench-model configurations. The injected resistances, cutouts and installed
test limits are `UNVERIFIED_ESTIMATE` fixtures. The results establish no
post-failure physical validity or flight clearance.

## Plant and controller contract

- `packages/physics/propulsion/dataset.py` maps the same tick's local branch
  voltage to full-throttle RPM using the existing bench-plane mapping. It caps
  RPM at the static-table maximum and maps it to a thrust ceiling. Below the
  minimum static RPM it uses the existing static square-law assumption.
- `packages/physics/scenarios/runner.py` computes the operating point from the
  tick-start SOC and current control request. It solves
  `V_bus = OCV(SOC_start) - R_pack * sum(I_i)` to within 0.0001 V.
  The default branch shares the bus. A declared series resistance uses
  `V_i = V_bus - R_i * I_i` within the same dataset voltage support.
  The model computes branch current from the RPM of the **delivered** thrust.
  The prior tick's bus voltage seeds the solve. The solver commits SOC and
  energy after resolving load and brackets the existing battery cutoff.
- `packages/physics/controller/mixer.py` projects each nominal rotor request
  onto its attainable ceiling. `packages/physics/controller/attitude.py`
  records delivered minus requested wrench in order
  `[collective N, roll N*m, pitch N*m, yaw N*m]`, along with the final
  saturation and residual counts. The rigid-body solver and frame monitor
  receive the same delivered thrust vector.
- `packages/physics/propulsion/branches.py` defines optional per-branch current,
  minimum and maximum voltage, RPM, thermal dwell and actuator thrust ratings.
  IDs are zero-based design rotor indices. Existing shared motor and ESC
  limits are checked at each live branch. The thermal criterion is seconds
  above a declared current, with an in-tick crossing. It does not estimate
  winding temperature. The legacy 2x continuous-rating destructive rule is a
  heuristic (`UNVERIFIED_ESTIMATE`), not a measured destruction threshold.
- `motor_cutout` and `esc_cutout` model one branch disconnected at the first
  control tick at or after the requested time. Its ceiling, thrust, reaction
  torque, RPM, current and modeled load-side voltage are zero. Surviving
  branches retain their nominal allocation before voltage projection. The
  existing controller can respond to the changed attitude and altitude on
  later ticks. No fault-tolerant redistribution, spin-down transient, failed
  propeller drag or safety behavior is modeled.
- A limit excursion or cutout adds a structured entry keyed by
  `<component>:<branch_id>` in `ScenarioResult.component_verdicts`. It
  contains `status`, `component`, `branch_id` and `findings`. Each finding
  carries the limit, absolute time, verdict, and measured-in-model value,
  applicable threshold and units when available. Existing aggregate component
  keys remain string verdicts. Hard limits stop integration before the
  violating tick advances rigid-body state. For a bracketed electrical limit,
  SOC and energy account for the interval through the crossing. A supported
  cutout latches overall `FAIL` even if a user criterion happens to pass.
- Blade breakup, winding-short drag, unmodeled reallocation and other unknown
  fault types stop before the first affected control update with a
  branch-specific `INCONCLUSIVE` finding. A missing branch electrical model
  or unsupported wiring operating point also refuses the affected branch.
  A separately observed `FAIL` takes precedence in the overall flight
  verdict while any `INCONCLUSIVE` finding remains recorded. The shared
  flight service exposes the overall verdict and combined mission success.

## Reproducible software measurements

Run `pytest tests/acceptance/test_p0a_012.py -q -s` to print the telemetry
summaries. The tests use a 4 ms control period and the existing rigid-body
plant. Within this test, the only pack change is resistance.

| MN3508 6S climb and turn | Nominal 0.020 ohm | Sagged 0.115 ohm |
| --- | ---: | ---: |
| Minimum bus voltage (V) | 24.1847 | 20.1274 |
| Minimum sum of branch thrust ceilings (N) | 73.7460 | 62.6656 |
| Peak delivered collective thrust (N) | 73.7460 | 62.6685 |
| Largest collective shortfall (N) | 6.7701 | 26.2755 |
| Saturated / torque residual ticks | 33 / 33 | 84 / 84 |
| Final altitude (m) | 3.8011 | 3.6292 |
| Mission target (>3.7 m) reached | yes | no |
| Flight verdict | NO_MODELED_LIMIT_BREACHED | NO_MODELED_LIMIT_BREACHED |

The largest paired tilt difference is 3.215 degrees. The sagged case misses
the mission criterion while remaining within the checked hard limits.
The tests check the bus voltage against start-of-tick SOC and delivered
branch current on every tick.

For both motor and ESC cutout on branch 1, activation at 0.081 s is observed
at 0.084 s. Total available thrust falls from 73.7460 N to 55.3095 N. Actual
collective falls from 45.8568 N to 34.1432 N on that tick, with residual
`[-11.7136 N, -2.9284 N*m, -2.9284 N*m, +0.1757 N*m]`. At the
0.260 s attitude-loss abort, healthy versus failed altitude is 2.0825 m
versus 2.0234 m, and tilt is 6.904 degrees versus 47.309 degrees. The
reference 60 kg hexacopter loses branch 0 at 6.000 s and aborts on
unrecoverable attitude at 6.424 s. All cutout cases record `FAIL`.

Tests verify isolated branch limit findings including a wiring-drop case and
a thermal crossing at 0.006 s, refuse unsupported mechanisms both at start
and during flight, compare seeded reruns byte for byte, and verify that
delaying a fault cannot change earlier states or electrical outputs.
