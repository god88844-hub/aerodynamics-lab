## Physics added/corrected

`packages/physics/propulsion/battery.py` (existing method semantics kept
byte-identical — the frozen M21 benchmarks call them):

1. **Causal bus equation**: `V_bus = V_oc(SOC) - V_rc - I·R_int`, with `V_rc`
   a caller-owned polarization state (0 by default — no sourced RC parameters
   exist yet) and `V_oc` the declared OCV table at its declared measurement
   conditions (temperature dependence is NOT modeled — declared limitation,
   consistent with the M9 audit).
2. **Exact constant-power solve** (`solve_constant_power`): substituting
   `I = P/V_bus` gives `V_bus² - V_th·V_bus + P·R = 0` with
   `V_th = V_oc - V_rc`; the **stable upper root**
   `V_bus = (V_th + sqrt(V_th² - 4·P·R))/2` is returned (the lower root is
   the unstable constant-power equilibrium). Demands above the maximum
   deliverable power `V_th²/(4R)` (negative discriminant) return
   `feasible=False` with a named reason — voltage collapse, never an invented
   operating point. Deterministic exact algebra, no iteration.
   `max_deliverable_power_w` exposes the collapse boundary.
3. **Strict declared OCV support**: the PCHIP no longer extrapolates; a SOC
   below the declared table's lowest point (the uncalibrated knee region)
   raises `OutOfSupportError` (fail closed, no optimistic invented tail).
4. **Deterministic crossing brackets** (`crossing_time_below_cell_v`): first
   time in `[0, dt]` at which the loaded cell voltage reaches a threshold
   while the pack drains linearly at constant current. Equality is inclusive
   (`<=`): a start-of-tick crossing returns exactly 0.0, an exactly-zero
   bracket endpoint returns the edge exactly, interior crossings are bracketed
   by 60 bisection halvings on the model's own OCV interpolation (float
   precision, bit-reproducible). A drain leaving the declared support before
   the threshold raises `OutOfSupportError`.
5. **Typed refusals**: `VoltageCollapseError(PowertrainError)` (no feasible
   operating point) and `OutOfSupportError(PowertrainError)` (outside
   declared support).

`packages/physics/scenarios/runner.py` (the authoritative plant):

6. **Causal per-tick order**: the bus solve, current lookups, power gate and
   event brackets all use the start-of-tick SOC; no step reads a later
   SOC/current than its clock. The damped fixed-point bus solve is seeded
   with the previous tick's converged bus voltage (past state only),
   converges to 1e-4 V within 24 iterations (matching
   `StaticPowertrain.solve_bus`), and **non-convergence is now a declared
   refusal** (it was previously a silently accepted last iterate).
7. **Attainable-output gate**: the converged demanded electrical power must
   lie inside the pack's exact constant-power boundary; above it the plant
   raises `VoltageCollapseError` — the commanded propulsion output is *not
   attainable* and is *not simulated*. A sagged bus leaving the measured
   motor-data voltage excursion mid-solve is converted to the same typed
   refusal (previously an untyped `ValueError` crash).
8. **Exact event bracketing**: `battery_cutoff`/`battery_warning` events carry
   their bracketed crossing offset within the tick; the runner stamps the
   absolute event time `t + tau`. Equality and tick-edge crossings fire
   deterministically. The warning fires **once** at its crossing (latched)
   instead of every tick.
9. **Verdict propagation**: fail-closed powertrain refusals become named
   critical events (`battery_voltage_collapse` / `battery_out_of_support` /
   `powertrain_refused`) — no invented post-failure thrust or state; the last
   recorded sample is the pre-failure state at the refusing tick.
   `ScenarioResult.component_verdicts` records per-component verdicts:
   `FAIL` (declared hard limit breached; battery_cutoff/collapse→battery,
   motor overcurrent/burnout→motor, esc overcurrent/overvoltage→esc,
   structure_yield→frame), `NO_MODELED_LIMIT_BREACHED` (explicitly NOT a
   fitness claim), `NOT_SIMULATED`. `run_flight` surfaces
   `component_verdicts` in the report.

**Honest result: the repaired causal model's held-out numbers are BIT-IDENTICAL
to the frozen baseline — zero improvement, and the pre-registered knee-anchor
hypothesis is REFUTED.** The evaluation establishes why:

- The fitted support already spans the knee: calibration cycles 1–50 discharge
  to 4.8206 Ah of the 5.0 Ah nameplate, so the declared OCV support reaches
  **3.5628 % SOC**. The held-out crossings occur *inside* the calibrated
  support, not in an uncalibrated extrapolation tail.
- The deficit is the **aged module's loaded voltage inside the calibrated
  support** (early-life fit vs aged behavior: replay bias +0.389/+0.740 V,
  forecast bias +0.216/+0.317 V with max errors 1.3–9.2 V at the deepest
  discharge). This is unobservable from cycles 1–50: the aged state (capacity
  fade / impedance growth) is not measurable from early-life data, so no
  causally-calibrated model form can recover it. This is a **data limitation,
  not a model-form limitation** — the P0A-005 root-cause clue ("cutoffs occur
  beyond the largest calibrated cumulative charge") is corrected by this
  evaluation: the cutoffs occur within the charge support.
- The timing information exists in the model state (the lower band warns in
  100/100 with zero misses, median lead 8/6 s); the absolute low-voltage
  accuracy under aging is the remaining deficit.
- The knee-anchor probe (declared component-table tail shape joined at the
  support boundary, dense-resampled so the fitted region is preserved to
  <1e-6 V/cell — an earlier splice implementation that re-shaped the fitted
  region was corrected before any held-out number was allowed to inform the
  repair) recovers **zero** crossings: refuted, published as evidence.

No future-information leakage: the repair uses only the frozen fit (cycles
1–50), declared component-table priors, and the frozen guard margin; no
held-out cycle informed any parameter, threshold or structure; the probe ran
once after pre-registration and its refutation is published as-is.
