# M29.8 — Directly recomputed cross-domain virtual decision gate

`physics.validation.direct_virtual_case.audit_direct_virtual_case` integrates M27.9 and M28.10 from **primary operator-supplied numerical inputs**. It runs the calibrated-ADC sensor holdout engine and continuous rotor-pair clearance engine itself, rather than accepting an arbitrary externally supplied `passed=true` flag. The frozen model/protocol must match the sensor case, every decision threshold must reference exactly the calibrated channel and **matching physical unit**, and every decision is explicitly enumerated. The design itself drives the geometry check.

For each critical threshold the software takes the *maximum reported calibration-inclusive conservative residual* across held-out groups, then adds user-declared further absolute model-form, numerical, input and geometry hard bounds. For failure above a maximum it calculates `limit-predicted-total_assumed_bound`; for failure below a minimum it calculates `predicted-limit-total_assumed_bound`. Only a strictly positive margin and passing directly recomputed sensor/rotor analytical checks produce `DIRECTLY_RECOMPUTED_VIRTUAL_CASE_CONSISTENT_UNVERIFIED`. A failed source, rotor collision possibility, incompatible frozen identity/channel/measurement unit, missing bound, contradictory operator data or negative margin blocks the analysis. Canonical SHA-256 fingerprints are deterministic and capture decision metrics and sources.

**Core scientific caveat:** Even an actual held-out maximum empirical residual is **not** automatically a worst-case physical error bound for unmeasured future conditions; a fully validated model-form hard enclosure requires independent experimental evidence, domain coverage, calibrated instruments, authenticated test custody and confirmed hardware identity. The supplied measurements/geometry are unauthenticated, so the analytical green status has no empirical safety probability or physical release meaning. Actual-physical-source, flightworthiness, hardware clearance, predictive equivalence and manufacturing/flight authorization flags are always false.
